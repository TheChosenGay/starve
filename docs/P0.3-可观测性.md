# P0.3 服务端可观测性

> 状态：已实现（2026-08-20）

## 边界

业务包只依赖 `TickObserver`、`SaveObserver` 和 `GatewayObserver`。OpenTelemetry 与 Prometheus 依赖集中在 `internal/observability`，ECS、世界模拟和网关业务不引用监控 SDK。

`CompositeTickObserver` 同时扇出 slog 与指标。Actor 运行时提供只读、近似的邮箱 `depth/capacity` 快照；快照不可用于业务决策。

## 指标

- `starve_tick_duration_seconds`：tick 执行耗时直方图，单位秒；
- `starve_tick_overbudget_total`：超过 tick 预算的累计次数；
- `starve_actor_mailbox_depth` / `starve_actor_mailbox_capacity`：按
  `actor_kind` 聚合的近似邮箱深度与容量；
- `starve_gateway_raw_connections` / `starve_gateway_sessions`：当前原始
  WebSocket 连接数与已登录会话数；
- `starve_gateway_rejects_total`：按有界 `reason` 统计的网关拒绝次数；
- `starve_snapshot_full_bytes` / `starve_snapshot_delta_bytes`：全量与增量
  protobuf 编码尺寸直方图；
- `starve_save_duration_seconds` / `starve_save_bytes` /
  `starve_save_errors_total`：按 `trigger` 统计的存档耗时、编码尺寸和失败。
- `starve_action_started_total` / `starve_action_committed_total` /
  `starve_action_completed_total` / `starve_action_canceled_total` /
  `starve_action_rejected_total`：按有界 `kind`、`reason` 统计动作生命周期；
- `starve_action_active`：当前仍持有 `ActionState` 的实体数量。
- `starve_combat_impact_total`：按有界 `result`（hit / blocked / miss / immune）
  统计权威攻击提交结果；
- `starve_health_changed_total`：按有界 `cause`（attack / poison /
  starvation / weather / healing）统计实际非零血量变化。

动作 lifecycle 指标在 `WorldEvent.outcome` 生成时记录一次；deprecated 的
`world.action.outcome` 独立 route 不再由服务端主路径推送，因此不会重复计数。

`manual`、`shutdown` 的存档耗时表示世界状态序列化耗时；`event` 还包括
宿主 `saveSink` 的持久化耗时。当前客户端手动保存路由只触发序列化，不改变
既有持久化语义。

标签只使用 `actor_kind`、`trigger`、`kind`、`reason`、`result`、`cause`
等有界枚举。禁止 UID、entity ID、action ID、request ID、connection ID
和自由文本进入标签。
时间直方图使用毫秒级边界，快照和存档使用 128B～1MiB 的二进制量级边界，
避免 OTel 默认秒级桶无法分辨 50ms tick。

## HTTP 与生命周期

Gateway 独立运行指标 HTTP 服务：

- `GATE_METRICS_ADDR`：监听地址，默认 `127.0.0.1:9090`；
- `GET /metrics`：Prometheus 抓取入口；
- `GET /healthz`：进程健康检查，成功返回 `200 ok`。

指标 HTTP 与 WebSocket 使用同一个 signal context。收到 `SIGINT`/`SIGTERM` 后，WebSocket、指标 HTTP、OTel provider 和 Actor engine 均按各自生命周期优雅关闭。

本地验证：

```bash
go run ./cmd/gate
curl http://127.0.0.1:9090/healthz
curl http://127.0.0.1:9090/metrics
```

## 本地 Grafana

`deploy/observe` 提供本机 Prometheus + Grafana，不进入 `make check`，也不改业务代码。

1. 指标口必须让 Docker 网桥访问到，先停掉只绑 `127.0.0.1` 的 gate，再启动：

```bash
make run-gate-observe
```

2. 另开终端启动看板：

```bash
make observe
```

3. 打开 [http://localhost:3000/d/starve-server](http://localhost:3000/d/starve-server)

匿名只读即可；账号 `admin` / `admin` 可改面板。Prometheus 在 [http://localhost:9091](http://localhost:9091)。Godot 登录或 `make e2e` 一次后，会话数和全量快照才会有点。动作区包含生命周期速率、取消原因与当前 active gauge。

停掉看板：

```bash
make observe-down
```
