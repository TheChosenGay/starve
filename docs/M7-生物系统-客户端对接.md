# M7 生物系统：客户端对接文档

> 范围：客户端把服务端生物（Creature）渲染出来并接入交互。协议无新增路由——
> 攻击/拾取复用现有 `world.player.attack` / `world.player.pickup`。

## 1. 快照里新增的组件

生物实体 = `Position + Health + Moveable + AOI + Creature + AI + Weapon`（快照均可读）：

| 组件 | 字段 | 客户端用途 |
| --- | --- | --- |
| `Creature` | `kind`、`threats`、`home_x/y`、`roam_radius`、`drops` | 渲染哪种生物；掉落提示 |
| `AI` | `state`（0=idle 1=chase 2=attack 3=flee）、`target`、`flee_hp`、`last_hit_by/at`、`hostile_players`、`hostile_kinds` | 状态机 → 动画；血条旁的状态提示 |
| `Weapon` | `attack_range/damage/cooldown` | 可选：显示攻击范围 |
| `AOI` | `radius`、`visible`（**仅 debug 模式编码**） | `GATE_DEBUG_AOI=true` 时画感知圈/视野线 |
| `Health` | `cur/max` | 血条 |

`CreatureKind` 枚举（`game_pb.ts` 里 `CreatureKind.RABBIT/WOLF/BOAR/DEER/SPIDER`）：

| kind | 表现 | 行为 |
| --- | --- | --- |
| RABBIT 兔子 | 小、棕色 | 被动，被打会逃跑；掉肉 ×1 |
| WOLF 狼 | 灰、中等 | 主动猎兔/玩家；掉肉 ×2 |
| BOAR 野猪 | 深棕、大 | 高血量近战，主动；掉肉 ×3 |
| DEER 鹿 | 白/褐、大 | 被动，低血逃跑；掉肉 ×2 |
| SPIDER 蜘蛛 | 小、紫黑 | 低血量快速，主动；掉肉 ×1 |

## 2. 渲染建议

1. **按 kind 给外观**：每个 kind 一张贴图/骨架动画（尺寸建议：兔子/蜘蛛 < 玩家，狼 ≈ 玩家，野猪/鹿 > 玩家）；没有贴图时先用颜色块区分（参考颜色）。
2. **状态机 → 动画**：`AI.state` 直接映射动作——`idle` 待机/游荡、`chase` 跑步、`attack` 攻击前摇/挥击、`flee` 逃跑（更慌张/更快）。
3. **血条**：有 `Creature` 的实体画血条（`Health.cur/max`）；非满血才显示。
4. **受击反馈**：`Health` 变化时可做闪白/飘字；`AI.last_hit_by` 可用于"谁打了它"的提示（可选）。
5. **掉落**：生物死亡 → 实体挂 `Loot`（肉），按现有掉落物渲染 + 拾取。
6. **地图变大**：`configs/map.json` 已从 80×80 扩到 **128×128**（出生点移到 64,64），相机/缩放建议适配更大视野；`MapConfig` 结构不变，渲染逻辑不用改。

## 3. 交互（无新协议）

- 玩家攻击生物：复用 `world.player.attack`（target_entity = 生物实体 id）；服务端统一走 `ApplyAttack`（扣血 + 受击标记 + 仇恨 + 打断）。
- 拾取掉落：复用 `world.player.pickup`。
- 客户端无需感知 AI 细节，只看 `state` 做表现。

## 4. 调试

- 服务端 `GATE_DEBUG_AOI=true`：每只生物快照带 `AOI.visible`（当前视野内的实体 id），可画感知圈/连线。
- `GATE_AOI_INTERVAL`（默认 4）可调感知刷新频率。

## 5. 服务端对照

- 组件/系统：`components/creature.go`、`components/ai.go`、`components/weapon.go`、`components/aoi.go`、
  `systems/ai_system.go`、`systems/aoi_system.go`、`worldmap/walkgrid.go`（A* 寻路）。
- 配置：`configs/creatures.json`（模板）、`configs/map.json`（handplaced.creatures 手摆出生）。
