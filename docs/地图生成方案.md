# 地图生成方案（阶段 1 已落地）

> 与客户端契约对齐：客户端只消费地形高度场（见 start-client `MAP-地形契约设计.md`），
> 服务端负责生成/存储/下发。本方案描述服务端实现。

## 1. 分工

| 端 | 职责 |
| --- | --- |
| 服务端 | 确定性生成地形高度场 + 地块类型 + 实体撒点；存档保存；随 `world.config` 下发 |
| 客户端 | 纯渲染：角高度四边形 + 边墙 + 角色按高度站立；不做地形生成 |

## 2. 数据模型（与客户端契约一致）

- 地形 = **角高度场**：`width×height` 个格子 → `(width+1)×(height+1)` 个角；
- 每角一个高度（0~255，1 字节）+ 一个 `TerrainType` 枚举（WATER/SAND/GRASS/ROCK/SNOW）；
- 格子尺寸 = 1 世界单位（与移动/采集/工作站距离单位一致）；
- 静态地形：登录随 `world.config.map` 下发，随存档保存/恢复，不随 tick 变化；
- 移动/寻路暂不做地形判定（水先当贴图），后续单独加。

## 3. 配置（`configs/map.json`）

```json
{
  "width": 80, "height": 80,
  "spawn_x": 40, "spawn_y": 40,
  "terrain": { "hills": 10, "max_amp": 6, "rock_level": 6, "water_level": 1, "spawn_flat_radius": 8 },
  "handplaced": {
    "resources": [ { "kind": "berry", "x": 38, "y": 38, "action": "pick", "work": 3 } ],
    "stations":  [ { "type": "campfire", "x": 42, "y": 42 } ],
    "loot":      [ { "kind": "wood", "count": 3, "x": 39, "y": 40 } ]
  },
  "scatter": [
    { "kind": "berry", "action": "pick", "work": 3, "count": 20, "min_dist": 3 }
  ]
}
```

- **手摆**（`handplaced`）：出生区关键资源/工作站/初始可捡物资，保证开局可玩；
- **撒点**（`scatter`）：按 seed 确定性随机，`min_dist` 冲突检测；
- **高度参数**：随机山丘数量/幅度、岩石/水位阈值、出生点压平半径。

## 4. 生成算法（`internal/game/world/mapgen.go`）

```
MapGenerator{seed, spec}.Generate():
  1. 地形高度场：seed 化 rng 撒 N 个山丘（中心/半径/幅度）→ 高斯叠加 → 量化整数
  2. 出生点压平：半径内角钉为 0（松弛时跳过，保证平坦）
  3. 相邻角高度差 ≤ 1：确定性正反两轮松弛（出生区外）
  4. 类型映射：出生区强制 GRASS；h≤water → WATER；h==2 → SAND；h≥rock → ROCK；其余 GRASS
  5. 手摆 + 撒点实体：资源（Workable）/工作站/初始 Loot；撒点带 min_dist 冲突检测
```

- **确定性**：唯一随机源 = `rand.New(rand.NewSource(seed))`，遍历顺序固定；
- seed：`GATE_MAP_SEED`（默认 42），**随存档记录**（`WorldMeta.map_seed`），重放用同一种子；
- 有存档时**不重新生成**（地形/实体从存档恢复）。

## 5. 协议与存档

- `game.proto`：`TerrainType` 枚举、`MapConfig{width,height,corner_heights,corner_types,spawn_x,spawn_y}`；
- `GameConfig.map`：登录随 `world.config` 一次下发；
- `SaveData.map`：地形随存档保存/恢复；
- 客户端用 `MAP-地形契约设计.md` 的 tilemap 方案消费（阶段由客户端会话做）。

## 6. 测试

- 确定性：同 seed 两次生成一致，不同 seed 不同；
- 出生点压平：压平区内角高度为 0；
- 相邻差 ≤ 1（允许局部差 ≥2 = 墙，本阶段未刻意制造悬崖）；
- 实体不越界；存档/加载地形一致；world.config 含地形。

## 7. 后续（阶段 2）

- 区域/生物群系：区域图（rect + circle regions）+ 每区资源规则 + 类型绑定（草地→浆果、岩石区→燧石）；
- 连通性：区域相接约束 + 出生区 BFS 校验（保证"一块大陆"）；
- 移动/寻路按地形类型判定（水/墙不可走）；
- 高度增量变更（建造/破坏）另出契约。
