# 仇恨传播：组件契约与对账表

> 范围：让一个实体**参与群体仇恨**（被打 → 记仇 → 通知同类）需要哪些组件。
> 本篇是**对账清单**——加新生物/新技能时照着挂，漏了会**静默失效**（不报错、
> 不崩溃，只是"打了没反应"），这是本项目最难排查的一类 bug。
>
> 实现见 `internal/game/components/creature.go` 的 `SpreadThreatToAllies`
> 与 `internal/game/components/attackable.go` 的 `ApplyDamage`。

## 1. 一句话结论

**发送方**（想传播出去）需要 5 个组件：

```
Position + Health + Attackable + Creature + AOI
```

**接收方**（想被通知）只需要 3 个：

```
Position + Health + Creature
```

也就是说：一只**不会攻击**的生物照样会被通知到仇恨——这符合语义
（"看见同伴被打、记恨上那个人"不需要我自己能打架）。

## 2. 逐项对账表（每一条都经实测确认）

| 组件 | 缺了会怎样 | 代码依据 |
| --- | --- | --- |
| `Position` | AOI 网格索引不到、距离算不出 | `aoi_system.go` 第一轮 `ecs.Has[Position]` 检查 |
| `Health` | 进不了 `ApplyDamage`（第一行就 return） | `attackable.go:35` `!ecs.Has[Health](w, target)` |
| `Attackable` | 没有伤害入口可调用 | `attackable.go:33` 的接收者是 `Attackable` |
| `Creature` | 仇恨表不存在 + 拿不到 `Kind`（同类判定） | `creature.go:268` `!ecs.Has[AOI]` 之后立刻取 `Creature.Kind` |
| `AOI` | 找不到邻居、也没有传播半径 `Threat` | `creature.go:268` `!ecs.Has[AOI](w, victim)` 直接 return |

实测（四组组合，各造一只狼、看同伴收到几条间接仇恨）：

```
Creature=false  AOI=false  →  0 条
Creature=true   AOI=false  →  0 条
Creature=false  AOI=true   →  0 条
Creature=true   AOI=true   →  1 条   ← 唯一能传播的组合
```

> ⚠️ 对**接收方**而言，`Creature` 检查是**防 panic 的护栏**，不是冗余判断：
> `ecs.Get[T]` 在组件缺失时**会 panic**（`sparse_set.go`，不是返回零值）。
> 而玩家/掉落物/建筑都会出现在 `Visible` 里且没有 `Creature`，
> 少了那句 `Has` 检查，**一次普通攻击就能让服务器 panic**（已用变异测试验证）。

## 3. 接收方的额外门槛

`SpreadThreatToAllies` 遍历受害者的 `AOI.Visible`，对每个候选同伴逐一检查：

| 检查 | 不满足时 |
| --- | --- |
| `ally != victim && ally != attacker` | 跳过（不给自己/攻击者发） |
| `w.IsAlive(ally)` 且无 `Dead`/`Offline` | 跳过（不给尸体或离线实体记仇） |
| 有 `Creature` 且 `Kind == victim.Kind` | 跳过（**只传同类**，狼不会因野猪被打而愤怒）；缺 `Creature` 时若不放行会 **panic** |
| 有 `Position` | 跳过（算不出距离） |
| 切比雪夫距离 ≤ **受害者的** `Threat` 半径 | 跳过（**超出传播范围**） |

注意 `AOISystem` 第二轮只用 `Position + Health` 收集"可被感知者"
（`aoi_system.go:87` `Query2[Position, Health]`），所以**同伴必须有 `Health`
才能出现在别人的 `Visible` 里**。没有 `Health` 的实体即使挂了 `Creature`
也不会被通知。

## 4. 传播半径：`AOI.Threat`，不是 `AOI.Radius`

一个实体有三个半径，**语义不同**（业界通常也是分开的）：

| 字段 | 含义 | 典型取值 |
| --- | --- | --- |
| `AOI.Perception` | **感知半径**：我能发现谁（决定追击/潜行） | 小（狼 6） |
| `AOI.Threat` | **仇恨传播半径**：同伴被打时，多远内的同类被通知 | 大（狼 16） |
| `AOI.Radius` | `Visible` 的**覆盖半径** = `max(Perception, Threat)` | 派生值 |

- `Radius` 只用于"AOI 要标记多大一片格子"。**只查一份**，省一半方格标记成本；
  判断"是否在感知内"时用 `AOI.InPerception` 对 `Visible` 再做一次 O(1) 距离复核。
- 传播**显式取 `Threat`**（`ThreatRadius()`），不依赖 `Radius` 恰好等于 max。
- **半径取发起方（受害者）的，不取接收方的**。语义是"我被打时能通知多远内的同类"，
  这是受害者自己的属性。曾经错误地优先取接收方的，于是一只"半径很大的旁观者"
  会把消息扩散得比发起方预期的更远（实测：受害者 `Threat=3`，8 格外的旁观者
  仍被通知，因为旁观者自己的半径是 20）。
- `Perception`/`Threat` 为 0 时回退到 `Radius`（兼容只填 `Radius` 的旧写法）。

配置在 `configs/creatures.json` 的 `perception_radius` / `threat_radius`，
由 `internal/game/world/seed.go` 写入组件。

## 5. 加新生物的清单

走配置（推荐）：在 `configs/creatures.json` 加一条，字段齐全即可，
`seed.go` 会自动挂好全部组件。

```jsonc
{
  "kind": "wolf",
  "perception_radius": 6,   // 感知：小，保留潜行感
  "threat_radius": 16,      // 传播：大，狼群才响应得起来
  "behavior_tree": "predator",
  // ...
}
```

运行时动态生成实体的话，手工挂第 1 节那 5 个组件，并且**先跑一 tick 再攻击**：

> ⚠️ `AOI.Visible` 是 `AOISystem` 每 tick 重算的**派生缓存**，刚创建的实体它是空的。
> 不预热就攻击 → **完全不传播**（看起来像机制没生效，实际是时序问题）。
> 演示里踩过这个坑。

## 6. 伤害必须走 `Attackable.ApplyDamage`

仇恨的**唯一触发点**是：

```
Attackable.ApplyDamage
  → Effect → Creature.AddThreat          （规则①：设直接仇恨）
  → SpreadThreatToAllies                  （规则②：通知同类）
```

所以：

- ✅ 任何**最终调用 `ApplyDamage`** 的技能/陷阱/爆炸，传播**自动发生**，不用额外写代码
- ❌ **直接扣血**（`Health.TakeDamage` / `hp.Cur -= x`）**什么都不触发**：
  不记仇、不传播、`Threats` 里连条目都没有

`Health.TakeDamage` 是公开方法、名字看起来"就是扣血该用的"，很容易误用。
范围技能（爆炸/投掷）的正确做法是**对波及到的每个目标逐个 `ApplyDamage`**。

注意由此带来的一个语义：一发 AOE 打到 N 只同类，会触发 **N 轮各自独立的传播**。
若希望"一次爆炸只算一次群体通知"，需要额外去重——目前**没有**做。

## 7. 排查：打了没反应，按这个顺序查

| 现象 | 先查 |
| --- | --- |
| 完全不记仇 | 目标有没有 `Creature`？伤害是否走了 `ApplyDamage`（而不是直接扣血）？ |
| 自己记仇了，同伴没反应 | 受害者有没有 `AOI`？同伴在不在 `Visible` 里（`Health`？距离？） |
| 只有很近的同伴响应 | `AOI.Threat` 是不是没配、回退成了较小的 `Radius`？ |
| 异类也被通知了 | 不该发生——检查 `Creature.Kind` 是否设对（同类判定按 `Kind`） |
| 同伴刚锁定又立刻脱战 | 目标是否跑出了 `Threat` 半径或拴绳（`leash`）？ |
| 页面/客户端刚打开时第一下没反应 | `AOI.Visible` 预热问题（见第 5 节） |

调试开关：`GATE_DEBUG_AOI=1` 会把 `AOI.Visible` 编进快照，可直接看"谁看得见谁"。
