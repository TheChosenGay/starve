# 终端客户端（cmd/tui）：不开 Godot 也能测服务端

> 服务端仓库：`/Users/daishan/starve`
> 定位：**开发期**的轻量客户端。启动 < 0.2s、终端里跑、不依赖图形环境，
> 用来快速验证移动/寻路/避障/占位语义；**不是**玩家客户端（没有等距视角、动画、音效）。

## 为什么要有它

Godot 客户端启动慢、占资源，而且很多服务端改动（占位代价、寻路绕行、形状滑动、
占位物生命周期）其实**在格坐标系里看更清楚**：树该只挡格心一小块、建筑该占满整格、
A\* 该绕开而不是穿过——这些用字符网格一眼就能判断，用 3D 反而要转视角。

它同时是 CI 友好的：`-dump` 模式不需要 TTY，连上本地网关收一帧就退出。

## 用法

```bash
make run-gate                      # 一个终端起服务端
make run-tui                       # 另一个终端起 TUI（默认 uid=42）

go run ./cmd/tui -uid 43           # 换个账号，方便双人对拍
go run ./cmd/tui -dump -no-color   # 收一帧打印就退出（不需要 TTY）
```

> **常见错误**：`connection refused` / `dial tcp [::1]:8081: connect: connection refused`
> 表示**服务端没起**——TUI 只是客户端。另开一个终端 `make run-gate`，等服务端打印
> `listening on ws://localhost:8081/ws` 再回来跑。（命令本身也会把这段提示打出来。）

常用参数：

| 参数 | 说明 |
|---|---|
| `-addr` | 网关地址，默认 `ws://localhost:8081/ws` |
| `-uid` | 用户 ID；不带 `-token` 时按 uid 自签 dev token（与 `tools/pomelo-client` 一致） |
| `-token` / `-access` | 显式登录 token / 房间票据；本地单世界留空即可 |
| `-w` `-h` | 视口格数；0 = 按终端窗口自适应 |
| `-dump` `-wait` | 收一帧打印并退出 / 最长等待时间 |
| `-duration` | 最长运行时间；0 = 直到按 `q` |
| `-no-color` | 关颜色（管道、日志、CI 里更干净） |

## 按键

| 键 | 作用 |
|---|---|
| `WASD` / `hjkl` / 方向键 | 移动：**点一下走一小段（≈2 格），按住连续走** |
| `space` | 停（发 `(0,0)`） |
| `f` | 自动行为（空格键同款：服务端按 AOI 就近匹配、走过去或直接执行） |
| `e` | 对最近的可作业目标发对应动作（砍/挖/采，按目标的受激能力自动选路线） |
| `p` | 拾取最近的掉落物 |
| `c` | 切换**碰撞体叠加层** |
| `v` | 切换相机：**死区跟随 ↔ 居中跟随** |
| `r` | 强制重画 |
| `q` / `Ctrl-C` | 退出 |

## 移动手感（为什么不是"持续方向"直通）

服务端的移动语义是**方向保持**（按住持续输入、松开清方向），而终端**拿不到松键事件**——
直接转发按键的话，按一下就会一直走，表现为"整个世界在滚、停不下来"。

所以 TUI 这一层做了两件事：

1. **方向脉冲**：按键只发一次方向，`movePulse = 180ms` 后自动发停止。终端的自动重复会在
   按住时反复送来同一个字节，于是"点一下走一小段 / 按住连续走"两种直觉同时成立。
   `-walk-hold` 可以退回旧的"按一下就一直走"（脚本用）。
2. **相机死区**：默认不把玩家钉在屏幕正中，而是**在中央 1/3 内自由走动、视口不动**，
   走出死区才滚动。居中跟随会让"是我在动"变成"画面在动"（`v` 可切回居中）。

另外**自己那一格有醒目的亮青底色 + 四邻高亮**：相机跟随时"我在哪"全靠它。

## 画面怎么读

- 地形：`~` 水、`.` 沙、`"` 草、`^` 岩、`*` 雪
- 实体：`@` 自己（亮青）、`@` 他人（黄）、`T` 树、`A` 岩石、`*` 可采环境物、`o` 其它占位物、
  `#` 已放置建筑、`&` 工作站、`$` 掉落物、`w` 狼 / `d` 鹿 / `r` 兔 / `b` 野猪 / `s` 蜘蛛

底部两行是状态（位置 / 血量 / tick / 光照 / 实体分类计数 / 叠加层开关）与按键提示，
最近一次操作的结果会显示在状态行右侧。

### 碰撞体叠加层（`c`）

打开后，占位物的碰撞体覆盖到哪些格会被**背景色**标出来：

- `Block.Radius > 0`（树/岩）：按**格心圆**标（圆心在 `anchor + 0.5`，不是锚点本身）；
- `Block` 盒（建筑/工作站）：标满整个占格足迹；
- 服务端开 `GATE_DEBUG_COLLISION=1` 时优先用下发的 `DebugShape`——那才是服务端真正用的形状，
  用它来核对空间契约（盒以节点为中心、胶囊段在节点局部空间、四足沿局部 +Z）。

这是这个 TUI 最有用的地方：**不用开 Godot 就能肉眼验证"占位 ≠ 不可走"是否成立**——
树只该挡格心那一小块，相邻格照样能走；建筑该整格挡满。

## 实现要点（改它之前先看这里）

- **协议复用**：连接/握手/登录/编解码与 `tools/pomelo-client` 同一套
  （`internal/gateway/pomelo` + `pkg/proto`），命令只发 `world.player.*` 的 notify。
  服务端加新组件不需要改这里——解码按组件名，未知组件忽略。
- **单线程状态**：世界镜像只被主循环改；网络推送与按键都从 channel 进主循环，
  没有锁、也没有并发写状态（`cmd/tui/loop.go`）。
- **字符帧缓冲**：先写 `frame`，再一次性输出，避免闪烁；**宽字符（中文/全角）按两列**
  计算并标记延续列（`cmd/tui/render.go` 的 `runeWidth`/`put`），否则中文 HUD 会把布局挤歪。
- **坐标约定**：`Position` 是格锚点、`Position + sub` 是连续位置（移动体）；
  `Block` 的形状中心在 `anchor + 占格/2`（`nodeOrigin`）。叠加层的正确性靠
  `tui_test.go` 里的 `TestOverlayMarksTreeBoxAndCapsule` 锁住。

## 限制

- 只有俯视格视图，没有等距投影/高度/动画；
- 不做本地预测：位置完全以服务端快照为准（所以它验证的是权威行为，不是手感）；
- 只连一个世界，切房间要重启；
- 排行榜/背包/制作等面板没做，只有移动 + 自动行为 + 作业/拾取这几个最常用的。

## 冒烟

```bash
make run-gate &                    # 起服务端
make tui-dump                      # 连上收一帧（不需要 TTY）

# 连移动链路一起自检：发一次方向、等一会儿、比位置
go run ./cmd/tui -dump -move "1,0" -walk 1200ms
#   → 移动自检: 方向 (1,0) 持续 1.2s：(64,64)+0.00,0.00 → (74,64)+1.00,0.00
#     （位置没变会直接报错，所以这条能当 CI 冒烟）
```

`-dump` 还会打印**自己周围的地形/实体/角高度**，用来判断"这里为什么走得慢/走不动"：
走得慢看角高度（坡度因子），走不动看实体行（占位物/水）。
